# 编译程序实验报告 (Lexical, Syntax, Semantic & Codegen)

## 项目说明
本项目使用 C 语言实现了一个完整的简易编译分析程序。程序能够读取源代码字符流，并依次完成以下分析：
1. **词法分析**：使用折半查找识别保留字，过滤注释及空格，精准定位错误行号。
2. **语法分析**：采用递归下降分析法，构建并按格式输出语法树。
3. **语义分析**：通过符号表进行变量作用域和重复定义的检查。
4. **代码生成**：生成赋值语句的四元组（Intermediate Code）。

## 目录结构
- `yuyi.c`: 源代码文件
- `tests/`: 包含 5 个测试用例 (test1-test5.txt)
- `Dockerfile`: Docker 镜像构建脚本
- `docker-compose.yml`: 一键部署配置文件
- `README.md`: 本说明文档

## 部署与运行

本项目通过轻量级 Docker 容器支持包括 Windows、macOS 和 Linux 在内的跨平台一键部署。请确保本地已安装 [Docker](https://www.docker.com/) 及 Docker Compose。

**一键构建并执行测试**：
```bash
docker compose up --build
```
*该指令会自动拉取轻量级 alpine 镜像，编译 `yuyi.c`，并在容器内依次执行所有 5 个测试用例，最后将结果直接输出到控制台。*
